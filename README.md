# DID 번호호출 (안드로이드)

매장 TV에 매장 이미지와 호출 번호를 띄우고, 번호가 호출되면 팝업 + "딩동" + 음성으로 안내하는 앱입니다.
**앱 하나**를 설치하고 처음 실행할 때 역할만 고르면 됩니다.

| 기기 | 역할 | 하는 일 |
|---|---|---|
| 카운터 공기계 | 📱 **호출기 (호스트)** | 번호 입력·호출, 이미지·설정 보관, 호출 서버 (화면이 꺼져도 동작) |
| TV에 연결된 안드로이드 (TV박스, 구글TV 등) | 📺 TV 화면 | 호출기를 자동으로 찾아 호출 화면 표시 |
| TV에 연결된 윈도우 PC | 💻 브라우저 화면 | 크롬·엣지에서 `http://호출기주소:8765/display` |

모든 기기는 **같은 공유기(와이파이)**에 연결되어 있어야 합니다. 인터넷·가입 필요 없음.
TV 기기와 PC 화면은 같은 페이지를 쓰므로 **화면·딩동·목소리가 모두 똑같습니다** (음성은 호출기 폰이 만들어서 보냄).

---

## 1. APK 받기
GitHub 저장소 → **Actions** → 최신 "APK 빌드" → 아래 **Artifacts**의 `DID-number-call-apk` → 압축 풀면 `DID-Call.apk`

## 2. 설치
- **공기계**: APK를 카톡/드라이브로 보내서 열기 → "출처를 알 수 없는 앱" 허용 → 설치
- **TV 기기**: USB에 APK를 넣고 파일 관리자 앱으로 실행 (또는 *Send Files to TV* 앱으로 전송)
- **v1.1부터 업데이트는 덮어 설치**: 정식 서명 키로 서명하므로 새 APK를 그냥 설치하면 이미지·설정이 그대로 유지됩니다
  - 단, **v1.0 → v1.1 처음 한 번만** 기존 앱을 삭제 후 설치 (서명 키가 바뀌었기 때문)
  - 서명 키 비밀번호는 GitHub 저장소 Settings → Secrets → `DID_KEYSTORE_PASSWORD` (잃어버리면 업데이트 불가, 따로 보관)

## 3. 사용
1. **공기계**에서 앱 실행 → `호출기 (호스트)` 선택
   - 알림 허용 → 상단에 `● 서버 켜짐`, 그 아래 **이 폰 주소**가 표시됨
   - ⚙ → `꺼짐 방지 (배터리 최적화 제외)` 를 꼭 한 번 설정 (화면 꺼져도 서버 유지)
2. **TV 기기**에서 앱 실행 → `TV 화면` 선택
   - 자동으로 호출기를 찾아 연결 (빠른 검색 → 못 찾으면 네트워크 전체 검색, 최대 10초 정도)
   - 그래도 못 찾으면 `주소 직접 입력` → 호출기 앱 상단의 주소 입력
   - 연결되면 호출기 상단에 `TV/PC 화면 1대 연결됨` 으로 표시
3. 번호 입력 → **호출**

### 버튼
- **재호출**: 현재 번호 다시 안내 · **다음 번호**: 마지막 번호 + 1 · **화면 비우기**
- TV 리모컨: 확인 = 재호출(처음 한 번 호출기에서 허용), 오른쪽 = 다음 이미지, 뒤로 = 메뉴(화면 방향·화면 정보·다시 찾기·주소 입력·종료)
- 현재 번호·최근 호출은 호출기 폰에 저장되어 앱·폰을 다시 켜도 유지됩니다

### 호출기 화면 방향 (가로 모드)
- ⚙ → `화면 방향`: 자동 회전 / 세로 고정 / 가로 고정 (키패드 연결 시 가로 추천)
- 가로 화면 오른쪽 위 `키패드 숨기기 ▸` / `◂ 키패드` 버튼으로 화면 숫자 키패드를 넣었다 뺐다 (선택이 기억됨)
- 호출기 화면은 **잠금 화면 위에도 표시**되고, 블루투스 키패드를 누르면 화면이 켜져 바로 입력됩니다

### 다른 기기의 호출 권한 (호출기에서 승인)
- TV·PC **화면 보기**는 누구나 가능 (허용 필요 없음)
- 다른 폰·PC 브라우저에서 **호출·설정**을 하려 하면 호출기 폰에 **[허용] [거부]** 창(과 알림)이 뜸 → 허용 한 번이면 그 기기는 계속 사용
- ⚙ → `허용된 기기`에서 목록 확인·권한 빼기. 같은 와이파이의 손님이 장난 호출을 할 수 없습니다

### 블루투스 숫자 키패드
호출기 폰의 블루투스 설정에서 키패드를 연결하면 앱 화면에서 바로 사용됩니다 (USB OTG 키패드도 가능).
PC 브라우저 호출 페이지(`http://호출기주소:8765`)에서도 같은 키가 동작합니다.

**기본 키 배열** (텐키형). 키는 자유롭게 바꿀 수 있습니다: 호출기 앱 ⚙ → `키 설정` 또는 브라우저 페이지 → *키 설정*
- 동작을 고르고 키패드에서 원하는 키를 누르면 지정됩니다. 한 동작에 여러 키를 지정할 수 있고, ✕ 로 뺄 수 있습니다
- `텐키형 기본값` / `백스페이스형 기본값` 버튼으로 언제든 되돌리기
- 호출기 앱과 브라우저 페이지가 같은 설정을 씁니다. 숫자 키는 항상 번호 입력

| 동작 | 텐키형 기본값 | 백스페이스형 기본값 |
|---|---|---|
| 호출 | 텐키 Enter, Enter | 같음 |
| 다음 번호 입력 | 텐키 `+` | 같음 |
| 재호출 | 텐키 `*` | 같음 |
| 화면 비우기 | 텐키 `/` | 같음 |
| 입력 전체 삭제 | 텐키 `-`, Esc | 텐키 `-`, 텐키 `.`, Esc |
| 한 칸 지우기 | 텐키 `.`, Backspace | Backspace |

NumLock이 꺼져 있어도 키 위치로 인식합니다.

### 윈도우 PC를 호출 화면으로 쓰기
- 크롬·엣지에서 `http://호출기주소:8765/display` → 처음 한 번 화면 클릭(소리 켜기·전체화면)
- **간편하게**: 휴대폰 브라우저 페이지(`http://호출기주소:8765`) → *PC 브라우저를 호출 화면으로 쓰기* → `DID-Display.bat` 받기 → PC에서 더블클릭하면 엣지 전체화면 + 소리 자동
- 윈도우 켤 때 자동 실행: Win+R → `shell:startup` → 그 폴더에 bat 파일 넣기
- **화면 메뉴**: 화면 **왼쪽 위 모서리를 빠르게 3번 클릭** → `새로고침` / `최소화` / `종료`
  - 최소화·종료는 bat 파일로 열었을 때 동작 (bat이 숨은 도우미를 함께 실행). 최소화 후에는 작업 표시줄의 엣지 아이콘으로 다시 열기
  - 이전에 받은 bat 파일(키오스크 방식)은 빠져나올 수 없으니 **새로 받아서 교체**하세요
- PC 절전/화면 끄기는 *설정 → 시스템 → 전원*에서 "안 함"으로

### TV 이미지·동영상 (왼쪽 화면)
- 호출기 앱 ⚙ → `TV 이미지 추가` / `TV 동영상 추가` (갤러리)
- 또는 브라우저 페이지 → *TV 이미지·동영상* → `＋ 이미지·동영상 추가`, 썸네일 ◀ ▶ 순서 바꾸기, ✕ 삭제
- 이미지는 최대 2560px·고화질로 저장(선명하게). 이전에 올린 이미지는 다시 올리면 더 선명해집니다
- 동영상: mp4(H.264) · 1080p 이하 · 300MB 이하 권장. 끝까지 재생한 뒤 다음으로. 기본 무음, 소리를 켜도 호출 안내 중에는 작아짐
- 이미지·동영상 합쳐서 최대 30개 (호출기 폰에 저장)

### 화면 색감 · 세로 거치
- 브라우저 설정 → *화면 색감*: **선명**(기본, 검정 배경·밝은 글자) / 차분
- TV를 **세로로 달 경우**: TV 리모컨 뒤로 → `화면 방향` (왼쪽/오른쪽으로 돌려 단 방향 선택). PC는 윈도우 디스플레이를 세로로 바꾸거나 화면 메뉴(왼쪽 위 3번 클릭) → `화면 회전`
- 세로 화면 배치: 위 이미지·동영상 / 아래 현재 호출 → 최근 호출(한 줄에 2개)
- 화면이 흐리면: TV 리모컨 뒤로 → `화면 정보`(PC는 화면 메뉴)에서 실제 해상도 확인 — 720p 이하로 그리는 기기는 흐려 보일 수 있음

### 알림음 · 목소리 · 내 목소리
- ⚙ → `알림음 선택`: 딩동 / 띵동댕 / 실로폰 / 차임벨 / 띵~ / 삐빅 (누르면 미리 듣기), `내 소리 파일 올리기`(mp3·wav, 5MB 이하)
- ⚙ → `목소리 설정`: 음성 엔진(구글·삼성 등)·목소리·말하기 속도·높낮이 + 미리 듣기
- ⚙ → `내 목소리 녹음`: 숫자(일~구)·십·백·천과 "번호 뒤 문장"을 녹음하면 번호에 맞게 이어 붙여 안내 (예: 51번 = 오+십+일+문장)
  - 녹음이 다 되면 `음성 방식`을 **내 목소리**로. 빠진 조각이 있거나 9999보다 큰 번호는 기계 음성으로 대신 안내
  - 음성 문구(`{n}번 고객님…`)를 바꾸면 "번호 뒤 문장"도 다시 녹음하세요

### 영업 시간 · 마감 안내
- ⚙ → `영업 시간 · 마감 안내` (또는 브라우저 설정): 자동 마감 켜기, 영업 시작·마감 시각, 마감 멘트
- 마감 시각이 되면 알림음 + 마감 멘트 음성 1회 → TV·PC에 마감 화면 표시 → 다음 영업 시작 시각에 자동으로 사라짐
- `지금 마감 표시` / `마감 표시 끄기`로 직접 켜고 끌 수도 있음

### 키오스크 주문 연동 (조리중) — v1.2
키오스크 주문서를 호출기 폰이 받아 **조리중** 목록에 자동으로 올립니다.
1. 호출기 앱 ⚙ → `🧾 키오스크 주문 연동` → 켜기 → 저장
2. 키오스크 PC의 분기 프로그램에서 '네트워크 프린터' 주소를 **호출기 폰 IP : 9100** 으로 설정 (창에 표시됨)
3. 그 출력이 원래 주방 프린터로 가던 것이면 `주방 프린터로 넘겨주기`에 프린터 주소(예: 192.168.0.50:9100)를 넣으세요
- 조리중 번호를 누르면 호출, 길게 누르면 삭제, 빈 칸에서 [호출] = 가장 먼저 들어온 번호
- TV 오른쪽 칸: 위 = 현재 호출(노란색) + 최근 호출, 아래 = 조리중
- 재발행 주문서와 이미 있는 번호는 무시합니다. 최근 받은 주문서 기록은 같은 창 아래에 보입니다.

### 호출 팝업 · 최근 호출
- 호출 시 화면 가운데 팝업 → 깜빡임 → 설정한 시간(기본 10초) 후 사라짐
- 최근 호출은 호출된 지 **5분** 후 하나씩 사라짐 (설정에서 변경, 0 = 계속 표시)

### 안내 문구 바꾸기
호출기 앱 ⚙ → `이미지 관리 · 안내 설정 (브라우저)` → *호출 안내 설정*
- 음성 문구 (`{n}` 자리에 번호), 팝업 안내 문구, 음성 반복 횟수(0이면 딩동만), 팝업 시간, 최근 호출 표시 시간

## 문제 해결

| 증상 | 해결 |
|---|---|
| TV가 호출기를 못 찾음 | 호출기 앱이 켜져 있는지, 같은 와이파이인지 확인 (게스트 와이파이·"AP 격리"는 끄기). `주소 직접 입력` 사용 |
| 가끔 연결이 끊김 | 호출기 ⚙ → 꺼짐 방지 설정. 공유기에서 호출기 폰 IP를 **고정(DHCP 예약)** 하면 PC 화면 주소도 안 바뀜 |
| 음성이 안 나옴 | 호출기 폰 설정 → 텍스트 음성 변환(TTS)에서 **Google TTS + 한국어** 확인. 알림음은 항상 나옴 |
| 새 APK가 설치되지 않음 | v1.0에서 올라올 때 한 번만 기존 앱 삭제 후 설치. 그 뒤로는 덮어 설치 |
| 다른 폰에서 호출이 안 됨 | 그 기기 화면의 [허용 요청 보내기] → 호출기 폰에서 [허용] |
| TV 화면이 하얗거나 깨짐 | TV 기기의 *Android System WebView* 를 최신으로 업데이트 |
| 부팅 시 자동 실행 안 됨 | TV 기기: 첫 실행 때 "다른 앱 위에 표시" 허용. 호출기: 꺼짐 방지 설정 |

## 기술 메모 (개발자용)
- Java, 외부 라이브러리 없음, minSdk 21 / targetSdk 34
- 호출기: `HostService`(포그라운드 서비스)가 포트 8765 HTTP + 8766 UDP 검색 응답
  - 누구나: `/` `/display` `/display.bat` `/status` `/media` `/m/{name}`(Range 지원) `/voice?n=` `/voice/closing` `/chime` `/voices` `/auth/request` `/auth/check`
  - 승인 기기(`?t=토큰`): `/call` `/recall` `/clear` `/config` `/closing` `/voice/preview` `POST /media` `POST /chime/upload` `/media/delete|move|clear`
  - 호출기 폰만: `/auth/decide` `/auth/devices` `/auth/revoke`
- TV 화면: `Discovery`(지난 주소 → UDP 브로드캐스트 → /24 전체 HTTP 검색) 후 WebView로 `/display?app=1`
- `tools/*.html` 수정 후 `python3 tools/gen_pages.py` 로 Java 상수 재생성
