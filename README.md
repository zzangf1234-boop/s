# DID 번호호출 (안드로이드)

매장 TV에 호출 번호를 크게 띄우고 "딩동 + 음성"으로 안내하는 앱입니다.
**앱 하나**를 두 기기에 설치하고, 처음 실행할 때 역할만 고르면 됩니다.

| 기기 | 역할 | 하는 일 |
|---|---|---|
| TV에 연결된 안드로이드 (TV박스, 구글TV, 안드로이드 TV) | 📺 TV 화면 | 왼쪽: 매장 이미지 슬라이드 · 오른쪽: 현재/최근 번호 · 호출 시 가운데 팝업 + 딩동 + 한국어 음성 |
| 카운터 공기계 | 📱 호출기 | 키패드로 번호 입력 → 호출 / 재호출 / 다음 번호 / 화면 비우기 |

두 기기는 **같은 공유기(와이파이)**에 연결되어 있어야 합니다. 인터넷·서버·가입 필요 없음.

---

## 1. APK 만들기 (둘 중 하나)

### 방법 A — GitHub에서 자동 빌드 (PC에 아무것도 설치 안 해도 됨)
1. github.com 가입 → 오른쪽 위 **+ → New repository** → 이름 입력 → Create
2. **uploading an existing file** 클릭 → 이 폴더 안의 파일·폴더를 전부 끌어다 놓고 Commit
   (`.github` 폴더가 꼭 포함되어야 합니다)
3. 상단 **Actions** 탭 → "APK 빌드"가 3~5분 돌고 초록색 체크가 뜨면 클릭
4. 아래 **Artifacts**의 `DID-number-call-apk` 다운로드 → 압축 풀면 `DID-Call.apk`

### 방법 B — Android Studio
1. Android Studio 설치 → **Open** → 이 `DidCall` 폴더 선택
2. 동기화가 끝나면 메뉴 **Build → Build APK(s)**
3. `app/build/outputs/apk/` 에 APK 생성

## 2. 설치

- **공기계**: APK 파일을 카톡/드라이브로 보내서 열기 → "출처를 알 수 없는 앱" 허용 → 설치
- **TV 기기**: USB에 APK를 넣고 파일 관리자 앱(예: *X-plore*, *FX 파일 탐색기*)으로 실행
  - 또는 TV에 *Send Files to TV* 앱을 깔고 폰에서 전송
  - 설정 → 보안(또는 개발자 옵션) → "출처를 알 수 없는 앱" 허용 필요

## 3. 사용

1. **TV 기기**에서 앱 실행 → `TV 화면` 선택
   - 화면 하단에 `호출기 연결 주소 192.168.x.x:8765` 가 표시됨
   - Android 10 이상이면 "다른 앱 위에 표시" 허용 화면이 뜸 → 허용하면 **TV를 켤 때 자동 실행**
2. **공기계**에서 앱 실행 → `호출기` 선택
   - 자동으로 TV를 찾아 연결 (상단에 ● 연결됨)
   - 못 찾으면 상단을 눌러 TV 하단의 주소를 직접 입력
3. 번호 입력 → **호출**

### 버튼
- **재호출**: 현재 번호를 다시 안내
- **다음 번호**: 마지막 보낸 번호 + 1 을 자동 입력 (순번제 매장용)
- **화면 비우기**: TV 번호를 지우고 "잠시만 기다려 주세요" 표시
- TV 리모컨 **확인 버튼** = 재호출, **뒤로 버튼** = 종료/역할 변경 메뉴

### 앱 없이 호출 (보너스)
같은 와이파이의 아무 휴대폰 브라우저에서 `http://TV주소:8765` 접속 → 바로 호출 키패드가 나옵니다.
직원 개인 폰에서도 앱 설치 없이 사용 가능.

### TV 이미지 (왼쪽 화면)
- **공기계 앱**: ⚙ → `TV 이미지 추가 (갤러리)` → 사진 여러 장 선택 (자동으로 1920px로 줄여서 전송)
- **브라우저**: `http://TV주소:8765` → *TV 이미지* 열기 → `＋ 이미지 추가`, 썸네일의 ✕ 로 삭제
- 여러 장이면 슬라이드쇼 (간격 조절 가능), 표시 방식: *전체 보이기* / *꽉 채우기*
- 최대 30장, TV 기기 안에 저장되어 껐다 켜도 유지
- TV 리모컨 → 오른쪽 버튼 = 다음 이미지

### 호출 팝업
번호가 호출되면 화면 가운데에 큰 팝업이 뜨고 깜빡인 뒤, 설정한 시간(기본 10초) 후 사라집니다.
리모컨 뒤로 버튼으로 바로 닫을 수 있습니다.

### 윈도우 PC를 호출 화면으로 쓰기 (브라우저)
TV에 연결된 윈도우 PC의 크롬·엣지에서 `http://TV기기주소:8765/display` 를 열면 안드로이드 TV 화면과 똑같은 화면(이미지·팝업·딩동·음성)이 나옵니다.
- 처음 한 번 화면을 클릭하면 소리가 켜지고 전체화면이 됩니다 (브라우저 정책)
- **더 간편하게**: 휴대폰 브라우저 페이지의 *PC 브라우저를 호출 화면으로 쓰기* → `DID-Display.bat` 받기 → PC에서 더블클릭하면 엣지 전체화면 + 소리 자동 허용으로 바로 열림
- 윈도우 켤 때 자동 실행: Win+R → `shell:startup` → 그 폴더에 bat 파일(또는 바로가기) 넣기
- PC 절전/화면 끄기는 *설정 → 시스템 → 전원*에서 "안 함"으로
- 번호와 이미지는 안드로이드 TV 모드 기기가 관리하므로, 그 기기의 앱이 켜져 있어야 합니다 (안드로이드 TV와 PC 화면 동시 사용 가능)
- 음성은 윈도우에 설치된 한국어 음성(엣지는 자연스러운 온라인 음성)을 사용합니다

### 최근 호출 자동 사라짐
최근 호출 번호는 호출된 지 **5분**이 지나면 하나씩 사라집니다. *호출 안내 설정 → 최근 호출 표시 시간*에서 변경 (0 = 계속 표시).

### 안내 문구 바꾸기
호출기 앱 ⚙ → "TV 안내 문구·음성 설정" (또는 브라우저 페이지 하단 *TV 안내 설정*)
- 음성 문구: `{n}번 고객님, 주문하신 메뉴가 준비되었습니다.` (`{n}` 자리에 번호)
- 팝업 안내 문구, 음성 반복 횟수(0~5, 0이면 딩동만), 팝업 표시 시간

## 문제 해결

| 증상 | 해결 |
|---|---|
| 호출기가 TV를 못 찾음 | TV 하단 주소를 직접 입력. 공유기의 "AP 격리/게스트 와이파이"가 켜져 있으면 끄기 |
| 연결 끊김이 자주 남 | 공유기에서 TV 기기 IP를 **고정(DHCP 예약)** 해두면 주소가 안 바뀜 |
| 음성이 안 나옴 | TV 기기 설정 → 텍스트 음성 변환(TTS)에서 **Google TTS + 한국어** 설치. 딩동은 TTS 없이도 나옴 |
| 부팅 시 자동 실행 안 됨 | "다른 앱 위에 표시" 권한 허용. 일부 TV박스는 제조사 자동실행 설정을 따로 켜야 함 |
| TV 앱 목록에 안 보임 | 설정 → 앱 → 모든 앱에서 실행하거나, TV 홈의 "앱" 목록 끝을 확인 |

## 기술 메모 (개발자용)
- Java, 외부 라이브러리 없음, minSdk 21(Android 5.0) / targetSdk 34
- TV: 포트 8765 HTTP (`/call?n=`, `/recall`, `/clear`, `/status`, `/config`, `POST /image`, `/images`, `/img/{name}`, `/image/delete`, `/image/clear`), 포트 8766 UDP 자동검색 응답
- `tools/web.html` 은 브라우저 호출 페이지 원본 (`WebPage.java` 로 변환되어 포함됨)
