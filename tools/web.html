PC 브라우저를 호출 화면으로 쓰기

TV에 연결된 윈도우 PC의 크롬·엣지에서 아래 주소를 열면 TV와 같은 호출 화면이 나옵니다.

실행 파일을 더블클릭하면 엣지 전체화면 + 소리 자동 허용으로 열립니다. 윈도우 시작 시 자동 실행하려면 Win+R → shell:startup 폴더에 넣으세요. 화면 왼쪽 위를 3번 클릭하면 메뉴(새로고침·회전·최소화·종료)가 나옵니다. TV를 세로로 달았다면 메뉴의 [화면 회전]을 누르세요.
